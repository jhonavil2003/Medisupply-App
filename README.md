# Medisupply-App

## 🔐 Configuración Inicial

### API Keys
Este proyecto requiere configurar API keys de forma segura. Ver [SETUP_API_KEYS.md](./SETUP_API_KEYS.md) para instrucciones detalladas.

**Quick Start:**
1. Copia `local.properties.example` → `local.properties`
2. Reemplaza `TU_GOOGLE_MAPS_API_KEY_AQUI` con tu API key real
3. **Nunca subas `local.properties` a Git** (ya está en `.gitignore`)

Para GitHub Actions, configura el secret `GOOGLE_MAPS_API_KEY` en: **Settings → Secrets and variables → Actions**
